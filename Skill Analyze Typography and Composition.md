# Skill: Analyze Typography and Composition from a Reference UI

Category: Resource
Status: Not started

## Purpose

Use this skill to study a webpage or product UI and extract the design logic behind its typography and composition. The goal is not to describe the content, but to understand how the interface creates hierarchy, rhythm, clarity, mood, and balance.

This skill is especially useful when reviewing polished product marketing pages, editorial layouts, landing pages, portfolio sites, or app surfaces that feel unusually calm, intentional, premium, or well-resolved.

---

## When to use

Use this skill when the user wants to:

- understand why a page feels refined or cohesive
- break down typography choices and visual hierarchy
- extract layout principles from a reference website
- study spacing, density, rhythm, and composition
- translate visual observations into reusable design guidance
- create a design direction inspired by an existing UI without copying it

---

## What to analyze

### 1. Typography system

Identify:

- likely type categories used: serif, sans, mono
- display vs body roles
- headline behavior: size, weight, width, casing, tracking, line-height
- body text behavior: readability, width, spacing, contrast
- supporting text treatment: metadata, labels, captions, eyebrow text
- overall type mood: editorial, technical, calm, modern, restrained, warm, sharp

Questions to answer:

- What makes the typography feel distinctive?
- Is the system expressive or quiet?
- Where does hierarchy come from: size, weight, spacing, contrast, or placement?
- What is the relationship between headline type and body type?

### 2. Composition and layout

Identify:

- page structure and flow
- grid behavior: narrow, wide, modular, asymmetric, editorial
- alignment rules
- content width and line length
- use of whitespace and negative space
- image-to-text balance
- rhythm between sections
- how density is controlled

Questions to answer:

- What makes the layout feel calm or dynamic?
- Is composition driven by strict grid logic or optical balance?
- How does the page move the eye from one section to the next?
- Where does the design intentionally pause or breathe?

### 3. Visual hierarchy

Identify:

- first focal point
- secondary and tertiary information layers
- how navigation, metadata, headlines, body, and imagery are prioritized
- whether hierarchy is explicit or subtle

Questions to answer:

- What grabs attention first, and why?
- What recedes correctly into the background?
- How does the interface avoid visual competition?

### 4. Restraint and detail

Identify:

- whether the design relies on obvious styling or subtle decisions
- border usage
- color contrast and tonal control
- corner radius behavior
- captioning or annotation systems
- whether polish comes from decoration or discipline

Questions to answer:

- What is reduced or removed to make the page feel refined?
- Which small decisions create the strongest quality signal?

### 5. Reusable principles

Convert the analysis into practical guidance:

- principles to borrow
- patterns to avoid
- decisions that could translate into another product
- a concise design direction summary

---

## Output format

Structure the response in this format:

1. **Overall read**
    
    A concise impression of the page’s visual character.
    
2. **Typography**
    
    Break down hierarchy, type roles, tone, and readability.
    
3. **Composition**
    
    Explain grid, spacing, alignment, pacing, and visual flow.
    
4. **Why it works**
    
    Summarize the highest-leverage design decisions.
    
5. **Principles to apply elsewhere**
    
    Translate the observations into reusable design guidance.
    
6. **Optional design direction**
    
    A short creative brief for building something inspired by the same logic.
    

---

## Constraints

- Focus on design structure, not content strategy.
- Do not guess exact font names unless strongly supported.
- Avoid generic praise like “clean” or “modern” without explanation.
- Prefer concrete observations over stylistic adjectives.
- Explain cause and effect: what the design does, and what feeling or outcome it creates.
- Extract principles, not surface imitation.
